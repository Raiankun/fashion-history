# 装いの系譜／絵画の系譜／思想の系譜／医療の系譜

ファッションを入り口に、絵画など教養分野の流れを年表・系譜・用語でまとめた学習用サイトです。

| ページ | ファイル | 内容 |
|---|---|---|
| ファッション | `index.html` | 1858年〜2020年代のモードとランウェイ |
| 絵画 | `painting.html` | ゴシックから現代美術まで21の流派 |
| 健診ガイド | `kenshin-guide.html` | 一般健診・特定業務従事者健診・特殊健診の比較、制度史、安衛法・安衛則、有機則・特化則・じん肺法・騒音ガイドライン、実務の判断フロー（印刷・PDF保存可） |
| 特殊健診 | `exam.html?id=ex-organic` など | 11種類の健診ごとの専用ページ |
| 医療 | `medicine.html` | 医療の成り立ち、特殊健診の制度・歴史・条文、最新技術、薬、医療費 |
| 哲学 | `philosophy.html` | 古代ギリシャから現代まで、東洋と日本を含む15の時代 |

共通のスタイルは `site.css`、絵画と哲学のデータは `data/` にあります。

| 専用ページ | 例 | 内容 |
|---|---|---|
| 画家 | `artist.html?id=ar-monet` | 30人。要点、言葉、生涯と作品の年表（図）、年譜、影響の流れ（図）、同時代の画家との比較（図） |
| 名著 | `book.html?id=bk-iki` | 39冊。要約、要点、名言、構成、前提と影響（図）、時代の中の位置（図）、青空文庫・Gutenbergへのリンク |
`index.html` をブラウザで開くか、GitHub Pages で公開して閲覧します。

## ファッション（index.html）

- **A 年表**：1858年〜2020年代を12の時代に分け、出来事・人物・現在への影響を整理。各年代に「同じ時代の世界」（アメリカ・日本・アジアほか）
- **世界**：アメリカ、日本、アジア・アフリカほかのスタイルの系譜と人物・ブランド（出典付き）
- **B 7つの系譜**：時代をまたいで繰り返し現れる流れ（「アメリカの文脈」を追加）
- **C 用語集**：コレクション評やニュースでよく出る用語
- **D 今を読む**：トレンドを読むための視点と情報源
- **E ランウェイ**：ヨーロッパ12、日本3（コム デ ギャルソン、sacai、ジュンヤ ワタナベ）、アメリカ3（ザ・ロウ、マーク ジェイコブス、トム ブラウン）の計18ブランドのショー解説。ショーごとに構想、着想の源、系譜の流れ、評価、出典を掲載
- **F トレンド予測**：20〜30年周期、ミニマルと装飾の振り子、構造の変化から見た2027〜2029年の予測
- **G 着想の地図**：ショーが参照した過去の作品・人物・場所を、年代と種類で一覧

## 絵画（painting.html）

- **年表**：21の流派ごとに、文脈、見分けのサイン、代表作のギャラリーと表（作品・所蔵・見どころ・出典）
- **画像**：作者の死後70年を過ぎたパブリックドメインの作品だけ、英語版ウィキペディアの要約APIから閲覧時に代表画像を読み込んで表示。著作権保護期間中の作品は画像検索へのリンク
- **出典**：作品・流派・署名・ファッションとのつながりごとに、ウィキペディアや所蔵館などへのリンク
- **画家**：30人の生涯、画風、代表作、エピソード、言葉（出典付き）。パブリックドメインの肖像のみ表示
- **4つの流れ**：線と色／見たままと感じたまま／誰が絵を買うのか／日本との往来
- **見方**：5つの手順、見分けのサイン、図像の意味、画家の署名（すべて表）
- **用語集**：技法と美術用語
- **ファッションと絵画**：ファッション年表の該当年代へのリンク付き

## 哲学（philosophy.html）

- **年表**：15の時代・学派ごとに、中心の問い、文脈、キーワード、人物の表（生没年・主著・ひとこと）、今への影響、出典
- **名著と名文**：時代ごとに39冊の要約と名文。青空文庫で読める8冊は図書カードへ、海外の古典は Project Gutenberg へリンク。「名著」タブで一覧と絞り込み
- **6つの問い**：存在／知識／倫理／社会／言語／自己
- **読み方**：5つの手順、対立する立場、有名な言葉、思考実験（すべて表）
- **用語集**、**絵画・ファッションとのつながり**（両ページの該当箇所へのリンクと出典）
- 胸像写真の著作権に配慮し、画像は載せていません

## 医療（medicine.html）

- **医療の年表**：古代から個別化医療まで10の時代と、日本の医療制度のあゆみ
- **特殊健診**：一般健診との違い、2つの制度が並行して発展した流れ（図）、制度年表（裏付けの確認状況つき）、種類一覧、実施の流れ（図）、頻度緩和の条件、特定業務従事者健診の対象者が少なく見える理由（考察）
- **規則と条文**：法令の階層、健診の根拠条文、有機則・特化則・じん肺法・騒音ガイドラインの解説（e-Gov と厚労省資料へのリンク）
- **最新技術**、**薬の知識**（分類、後発品と薬価、飲み合わせ、飲むタイミング）、**医療費**（国民医療費の推移の図、負担割合、高額療養費のしくみと改正）、**用語集**
- 学習用の一般情報です。診断・治療・服薬・健診の実施判断は専門家や労働基準監督署に確認してください

## 注意

- 2026年10月時点の報道をもとに整理しています。人事や評価は変わることがあります。
- 解説は海外メディアなどの記事を日本語で要約したもので、各ショーに出典リンクを付けています。
- ランウェイ写真は著作権があるため掲載していません。写真はリンク先で見てください。
- ランウェイの「公式動画」は、`index.html` の `VIDEOS` にショーIDとブランド公式YouTube動画のIDを登録すると、その場で再生できる埋め込みになります（例：`"chanel-ss26":"XXXXXXXXXXX"`）。ショーIDは各ショーの左側に `#chanel-ss26` のように表示されています。未登録のショーはYouTube検索へのリンクになります。
- 各年代（`#era-0`〜`#era-11`）と各ショー（`#chanel-ss26` など）にはIDがあり、URLの末尾に付けるとそのページが直接開きます。表示されているIDを押すと、そのリンクをコピーできます。
- トレンド予測は仮説です。
