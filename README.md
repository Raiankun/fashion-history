# 装いの系譜

近代ファッションの誕生（1858年）から2020年代までの流れを、年表・系譜・用語・ランウェイ解説・トレンド予測でまとめた学習用サイトです。

`index.html` をブラウザで開くと閲覧できます。

## 内容

- **A 年表**：1858年〜2020年代を12の時代に分け、出来事・人物・現在への影響を整理
- **B 6つの系譜**：時代をまたいで繰り返し現れる流れ
- **C 用語集**：コレクション評やニュースでよく出る用語
- **D 今を読む**：トレンドを読むための視点と情報源
- **E ランウェイ**：主要12ブランドの2021〜2026年のショー解説。ショーごとに構想、着想の源、系譜の流れ、評価、出典を掲載
- **F トレンド予測**：20〜30年周期、ミニマルと装飾の振り子、構造の変化から見た2027〜2029年の予測
- **G 着想の地図**：ショーが参照した過去の作品・人物・場所を、年代と種類で一覧

## 注意

- 2026年10月時点の報道をもとに整理しています。人事や評価は変わることがあります。
- 解説は海外メディアなどの記事を日本語で要約したもので、各ショーに出典リンクを付けています。
- ランウェイ写真は著作権があるため掲載していません。写真はリンク先で見てください。
- 年表の各時代の画像は、メトロポリタン美術館の Open Access（CC0）画像を、閲覧時に公開APIから取得して表示しています。パブリックドメインと判定された所蔵品だけを表示するため、新しい時代ほど画像が出ないことがあります（その場合は美術館のコレクション検索へのリンクを表示します）。
- ランウェイの「公式動画」は、`index.html` の `VIDEOS` にショーIDとブランド公式YouTube動画のIDを登録すると、その場で再生できる埋め込みになります（例：`"chanel-ss26":"XXXXXXXXXXX"`）。未登録のショーはYouTube検索へのリンクになります。
- トレンド予測は仮説です。
